# Runtime dependencies for the API only — what `uvicorn app.main:app` imports,
# and nothing else. Use this on a host; use requirements.txt for development,
# ingestion, modelling and the test suite.
#
# The difference is not cosmetic. requirements.txt carries scikit-learn, pyarrow
# and pytest, which together are a few hundred megabytes that a free tier has to
# build and hold in RAM on every deploy, and which no request path touches.
#
# pandas and scipy ARE needed and cannot be dropped: the allocation correlations
# and the emerging level-persistence evidence are recomputed from the stored
# rows on each request by app/services/dashboard_service.py, rather than being
# stored pre-computed. That is why a restored database reproduces them exactly.
#
# Verified by installing this file alone into an empty environment and serving
# all five endpoints — see docs/04-deploy.md.
